What is DSA?

DSA stands for Data Structures and Algorithms. It is the art of organizing information and solving problems step by step — so your programs can work correctly and efficiently.

Think of finding a book in a library. How books are arranged is the data structure; how you find a book is the algorithm.

Lesson 01 — Foundations

Understand the two halves of DSA

You already use DSA ideas every day. A phone's contact list, a shopping cart, and map directions all depend on how data is stored and how problems are solved.

01 · Data structures

Where information lives

A data structure is a way to store and organize data. Examples include arrays/lists, stacks, queues, dictionaries/maps, trees and graphs.

02 · Algorithms

What to do with information

An algorithm is a clear sequence of steps that solves a problem, such as searching, sorting, finding a route or calculating a result.

03 · Efficiency

How well a solution scales

Two algorithms can produce the same answer but take different amounts of time or memory. This is why we study time and space complexity.

Try searching for 12.

Equivalent Python code

numbers = [8, 3, 12, 5, 9]
target = 12

for i, value in enumerate(numbers):
    if value == target:
        print("Found at index", i)
        break
else:
    print("Not found")

In the worst case, this algorithm checks every element. For n items, linear search takes O(n) time.
