# KBC Quiz Project - Four Roadmaps

This folder contains one KBC-style quiz project in four versions:

1. `js-version` - HTML, CSS, JavaScript and JSON
2. `react-version` - React with Vite
3. `angular-version` - Angular standalone component version
4. `flutter-version` - Flutter mobile app
5. `data/questions.json` - shared question bank

## Common Features

- JSON-based questions
- Four options
- Lock answer
- Correct/wrong highlighting
- Prize ladder
- Timer
- 50:50 lifeline
- Skip lifeline
- Audience poll lifeline
- Restart option

## Suggested Teaching Order

Start with `js-version`, then rebuild the same idea in React, Angular and Flutter.
