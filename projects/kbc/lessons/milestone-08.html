Milestone 08: Responsive Layout

Make the app work on mobile screens.

20% complete

🎯 Goal

Complete this milestone so the KBC HTML/JavaScript project moves one step closer to the final working app.

Rule: Do not open the full help before trying the task.

📄 Files to Open

📄 index.html📄 style.css📄 app.js📄 questions.json

🔨 Fully Defined Task

What to build

  • Open final-project and focus on Milestone 08: Responsive Layout.
  • Update index.html, style.css, app.js or questions.json as needed.
  • Implement only this milestone feature, not future features.
  • Run the app in the browser and test with at least two questions.
  • Fix all console errors before moving ahead.

Acceptance Criteria

  • Responsive Layout works in the browser.
  • The app has no console errors.
  • The UI still works on desktop and mobile.
  • The implementation uses JSON/state rather than duplicate hard-coded data.

Submit to Teacher

  • Screenshot of the working feature.
  • Short explanation of the changed code.
  • Git commit message for this milestone.

🧭 Step-by-Step Method

  1. Open the final-project folder.
  2. Open the files listed above.
  3. Make the smallest possible change for this milestone.
  4. Save the file.
  5. Refresh the browser.
  6. Check the output and the console.
