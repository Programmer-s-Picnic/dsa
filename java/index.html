CLASS 10 FOCUS

The destination is bigger than loops.

Once the foundation is stable, a Class 10 Java learner should move into the topics where longer programs become important: user-defined methods, classes and constructors, arrays, strings, searching/sorting and mixed problem solving.

ICSE students: this page is designed to grow into an ICSE Computer Applications revision and practice route. CBSE-affiliated school students: use it when Java is being taught by your school or as programming enrichment; the current CBSE Class X Computer Applications syllabus itself is not a Java syllabus.
