WHAT TO STUDY

Class X Java topic map

The Class X course begins by revising the Class IX Java foundation and then adds the major Class X programming topics.

1. Revision of the Class IX Java foundation
  • OOP concepts; objects and classes
  • Values, data types, tokens, type conversion
  • Operators, counters, accumulators and precedence
  • Input in Java and mathematical library methods
  • Conditional constructs
  • Iterative constructs and nested for loops

Use the current lesson library for this revision.

2. Class as the basis of computation
  • State and behaviour; member variables and member methods
  • Classes as abstractions and object factories
  • Objects as instances of a class
  • Primitive and composite data types
  • Instance, local and class-related variables; access and encapsulation concepts
3. User-defined methods
  • Need, definition, calling and returning values
  • Actual and formal parameters
  • Static and non-static methods
  • Method signature / prototype
  • Pure and impure methods
  • Pass by value; concept/example of reference passing as prescribed
  • Method overloading and modular programming
4. Constructors
  • Definition and characteristics
  • Default and parameterized constructors
  • Constructor overloading
  • Difference between constructors and methods
5. Library / wrapper classes
  • Wrapper classes and primitive/composite distinction
  • Autoboxing and unboxing
  • Numeric parsing: parseInt, parseLong, parseFloat, parseDouble
  • Character tests and conversion: isDigit, isLetter, isLetterOrDigit, isLowerCase, isUpperCase, isWhitespace, toLowerCase, toUpperCase
6. Encapsulation and variable scope
  • Identifying local, instance, argument/parameter and class variables
  • Private/public access and appropriate class design
  • Using data members and member methods together
7. Arrays, searching and sorting
  • Creating, accepting and traversing arrays
  • One-dimensional and double-dimensional arrays
  • Search techniques required by the syllabus
  • Sort techniques required by the syllabus
  • Programs that combine arrays with methods and classes
8. String handling
  • String methods and output tracing
  • Extracting and manipulating characters/substrings
  • Comparing and searching within strings
  • Programs such as palindrome/string transformation/alphabetical processing and other syllabus-style applications
Important: this is a student-friendly map, not a replacement for the official syllabus. Always check the CISCE document for the precise scope, prescribed methods and examination-year changes.
