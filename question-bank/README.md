# Learn With Champak bilingual question bank

Open `index.html` locally. Each topic has English, Hindi (Devanagari), and side-by-side modes; the selection is remembered in the browser. The 20 pages contain 1230 numbered questions. Search works offline. The optional Inter font needs a connection; system fonts are provided as fallback.

`questions.json` contains `en`, `hi`, and original `source` text for every question. Source questions were recovered from the attached PDFs, including wrapped lines. Technical names and identifiers remain in Latin script. These questions are for interview practice; no answer key is included.

Editorial note: English and Hindi conversions are systematic; review subject-specific phrasing with a teacher before formal publication.
