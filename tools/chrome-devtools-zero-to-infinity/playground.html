Before you begin

This practice page deliberately includes wrong CSS, a JavaScript calculation bug, a failing request, a console error and a mobile overflow. These are learning exercises, not production defects.

Open DevTools with F12 or Ctrl + Shift + I. Keep DevTools open while trying the buttons.

Lab A — Elements & Styles

This title is difficult to read. Inspect and fix its color.

Low-contrast example: Can you fix this in Elements → Styles?

Challenge: Inspect #poorContrastTitle; change its text color to #123b63. Edits in Elements are usually temporary.

Lab B — Console messages

Expected: entries appear in the Console. The ReferenceError includes a clickable source location. You are not harming this page.

Lab C — Find a real JavaScript bug

Result appears here.

Expected buggy result: 5 + 1 = 51, not 6. In Sources, find calculateSumBug and inspect typeof a. Think about Number().

Lab D — Network requests, status and JSON

Use Network → Fetch/XHR to inspect the request.

Click a request → Headers, Response, Timing, Initiator. If the 404 has a custom host response, the status is still visible in Network.

Lab E — Application → Local Storage

Inspect Application → Local Storage → this origin.

Never store real passwords or secrets in localStorage.

Lab F — Mobile responsive overflow

Toggle the Device Toolbar (Ctrl + Shift + M) and set viewport width to 360 CSS px.

This card uses min-width:680px on narrow screens. It causes horizontal overflow. Inspect .wide-card, disable that rule, and check whether the layout now fits.

Lab G — Performance and long tasks

Record in Performance before pressing.

Start a Performance recording, click the button, stop recording, and inspect main-thread work. Timing depends on the computer and is approximate.

Lab H — Accessibility and Lighthouse

Run Lighthouse for Accessibility, Performance, Best Practices and SEO. Also inspect the low-contrast labels and button names in Elements → Accessibility. Fix the issues one at a time and rerun.

Lab I — DOM change breakpoint

Watch me change.

In Elements, right-click #domTarget → Break on → Subtree modifications. Then click the button and inspect the call stack.
