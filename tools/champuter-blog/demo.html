Python Pandas · Creating DataFrames

A DataFrame is a two-dimensional table. It contains rows and columns and helps programmers examine structured data.

1. Create your first DataFrame

We can make a DataFrame directly from a dictionary whose keys become column names.

import pandas as pd

students = {
    "Name": ["Asha", "Ravi", "Meena"],
    "Marks": [85, 92, 78]
}
df = pd.DataFrame(students)
print(df)

2. Inspect the results

The variable df now contains a table. Each student occupies one row, and Name and Marks are column labels.

NameMarks
Asha85
Ravi92
Meena78

3. Filter the DataFrame

Use a condition to select only those students whose marks are at least 80.

passed = df[df["Marks"] >= 80]
print(passed)

Key points

  • A DataFrame is a table.
  • Columns have names.
  • Filtering selects rows that satisfy a condition.
