How to use this course

One new idea at a time

Do not read ten properties and try to remember them. At each stage: read the idea, predict the result, open the full code, paste it into the editor, then change exactly one value. The lesson deliberately repeats simple boxes so your attention stays on layout.

Main axis and cross axis

Flexbox always has a main axis and a cross axis.

With the default flex-direction:row, the main axis runs left→right and the cross axis runs top→bottom. justify-content works on the main axis; align-items works on the cross axis.

Header, sidebar, toolbar, cards, article, footer.

One main row/column → Flexbox. Explicit rows + columns → Grid.
