Flexbox + Grid

A very simple lesson. Learn just two ideas, see tiny examples, then change the code yourself in the editor.

Beginner Flexbox CSS Grid Learn by changing code

1. Remember only this

Flexbox = one direction Put items in a row or a column.
Grid = rows + columns Make a table-like layout of boxes.

2. Flexbox

We have three boxes. We want them next to each other.

Result
A
B
C
Flexbox code 
<div class="flex">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</div>

<style>
.flex {
  display: flex;
  gap: 10px;
}
</style>
Main line: display: flex;

3. Grid

Now we want six boxes in three columns.

Result
1
2
3
4
5
6
Grid code 
<div class="grid">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
  <div>5</div>
  <div>6</div>
</div>

<style>
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}
</style>
Main lines: display: grid; and grid-template-columns.

4. Use both together

A real page often uses Flexbox for a small row and Grid for the main boxes.

5. Tiny practice

  1. Make 4 boxes with Flexbox.
  2. Change Flexbox from a row to a column using flex-direction: column;.
  3. Make 6 boxes with Grid.
  4. Change the Grid from 3 columns to 2 columns.
  5. Try changing gap: 10px to gap: 30px.

Final summary

FlexboxOne row or one column.
GridRows and columns.

Do not overthink it. Start with the simpler one. You can use Flexbox and Grid on the same page.
