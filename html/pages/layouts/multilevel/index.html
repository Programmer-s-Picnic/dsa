The whole course in one sentence

FlexboxArrange and align items mainly along one axis: a row or a column.
GridDesign rows and columns together, then place items into that structure.
Golden rule: use the simplest layout that expresses what you want. Flex and Grid are partners, not competitors.

justify-content works on the main axis. align-items works on the cross axis. If you change flex-direction, the axes change too.

Property Useful values Question it answers
justify-content start, center, end, space-between, space-around, space-evenly How should free space be used along the main axis?
align-items stretch, start, center, end How should items align on the cross axis?
align-content start, center, space-between, stretch How should multiple wrapped lines align when extra cross-axis space exists?

  justify-content: center;
  align-items: center;

4
Flex item sizing

grow, shrink and basis

Flexbox is powerful because items can negotiate available space.

Property Meaning Common use
flex-grow How strongly an item takes extra space. flex-grow:1
flex-shrink How strongly an item may shrink when space is tight. flex-shrink:0 for fixed controls
flex-basis Preferred starting size before grow/shrink. flex-basis:200px
flex Shorthand: grow shrink basis. flex:1 1 220px
Responsive flex cards 
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.card {
  flex: 1 1 220px;
}
Common mystery: a flex child containing long text may refuse to shrink as expected. Try min-width:0 on that child.

Smart Grid sizing

repeat(), minmax(), auto-fit and auto-fill

This is where Grid becomes a responsive-layout machine.

Resize-friendly cards
A
B
C
D
E
Responsive Grid without a media query 
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}

auto-fit

Empty tracks collapse, so existing items can stretch and use the available room.

auto-fill

Keeps room for as many tracks as fit, even when some tracks have no item.

High-value pattern: repeat(auto-fit, minmax(...)) solves a huge number of responsive card layouts.

8
Responsive design

Let content decide, then add media queries

Modern layouts often start fluid. Add a media query only when the design actually needs a structural change.

Fluid Grid

grid-template-columns:
  repeat(auto-fit,
    minmax(220px,1fr));

Structural breakpoint

@media (max-width:700px) {
  .page {
    grid-template-columns:1fr;
  }
}
Avoid breakpoint collecting. Do not add 5 different breakpoints merely because devices have different names. Add one when your content stops fitting well.

11
Debugging

When Flexbox or Grid “doesn't work”

Problem Likely reason Check
Items are not moving The parent is not a flex/grid container. Is display:flex or display:grid on the correct parent?
Alignment seems to do nothing No free space exists on that axis. Give the container width/height or inspect available space.
align-content does nothing You have only one flex line. Use wrapping and enough cross-axis space.
Flex child overflows Intrinsic minimum size prevents shrinking. Try min-width:0.
Grid gets too wide A track or content has a large minimum size. Try minmax(0,1fr) or constrain the content.
Unexpected Grid items appear Implicit rows/columns were created. Inspect placement and grid-auto-*.
Order looks visually right but keyboard flow is odd Visual reordering differs from DOM order. Keep meaningful source order; avoid using CSS order as content logic.
Best debugging tool: use the browser DevTools layout overlays for Flexbox and Grid, then inspect the parent before the child.
12
Advanced control

Intrinsic sizing, subgrid and dense packing

min-content, max-content and fit-content()

These sizing tools let the content itself influence track or box size. They are useful when fixed pixels are too rigid and 1fr is too broad.

Content-aware sidebar 
.page {
  display:grid;
  grid-template-columns: fit-content(260px) minmax(0,1fr);
  gap:16px;
}

Subgrid

subgrid lets a nested grid align its tracks with tracks from the parent grid instead of inventing an unrelated inner track system.

Subgrid concept 
.cards {
  display:grid;
  grid-template-columns:repeat(3,1fr);
}

.card {
  display:grid;
  grid-template-rows:subgrid;
  grid-row:span 3;
}

Dense auto-placement

grid-auto-flow:dense may backfill visual holes when items have different spans. Use it carefully because visual order can differ from source order.

Advanced does not mean automatically better. Prefer simple, predictable source order and layout rules unless the design genuinely benefits from more complex placement.

Infinity

You no longer memorise layouts — you design them

“Infinity” is not another CSS property. It is the point where you can look at a design, divide it into containers, choose Flexbox or Grid for each container, make it responsive, and debug it when it breaks.

Think in containersBreak a page into navbar, hero, sidebar, toolbar, cards, forms, footer and other independent layout regions.
Choose the smallest toolUse Flexbox for one-axis distribution/alignment and Grid when explicit rows + columns make the structure clearer.
Let content breathePrefer fluid sizing, wrapping, minmax(), fractional tracks and meaningful minimum widths over rigid pixel layouts.
Preserve source meaningVisual rearrangement should not destroy logical reading, focus or accessibility order.
The final test: build a page from a screenshot without copying its CSS. If you can explain why each container uses Flexbox or Grid, you have reached the useful meaning of “0 → ∞”.
