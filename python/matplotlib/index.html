Before you write a single line

Matplotlib is a Python plotting library. Think of graph paper: the horizontal direction is called x, the vertical direction y. The point (2, 3) means move 2 units across and 3 units up. A line chart connects points, a bar chart compares categories, and a scatter plot displays individual observations.

LEVEL 0

What is a graph?

A graph is a visual way to show information. A point has an x-coordinate (across) and a y-coordinate (up). Start with one dot: (2, 3).

Python · runnable example
import matplotlib.pyplot as plt

plt.plot(2, 3, marker='o')
plt.xlim(0, 5)
plt.ylim(0, 5)
plt.grid(True)
plt.show()
Try it yourself: Change the point to (4, 1). Predict where it will move.

LEVEL 2

Your first line: x and y

The first list contains horizontal coordinates; the second contains vertical coordinates. Pair equal positions: (1,2), (2,4), (3,6). Connecting those points makes a line.

Python · runnable example
import matplotlib.pyplot as plt

x = [1, 2, 3]
y = [2, 4, 6]
plt.plot(x, y)
plt.show()

LEVEL 3

Figure, axes, labels, title

A figure is the whole drawing. Axes are the plot area and scales. Labels explain units; titles tell the story.

Python · runnable example
import matplotlib.pyplot as plt

days = [1, 2, 3, 4]
visitors = [12, 18, 16, 25]
plt.plot(days, visitors, marker='o')
plt.title('Visitors by Day')
plt.xlabel('Day')
plt.ylabel('Visitors')
plt.grid(True)
plt.show()

LEVEL 4

Colour, markers, line style, legend

Visual encoding tells readers what a line represents. Colour distinguishes series; markers show measured points; a legend identifies each series.

Python · runnable example
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
plt.plot(x, [2, 4, 3, 6], color='royalblue', marker='o', linestyle='-', label='Shop A')
plt.plot(x, [1, 3, 5, 4], color='tomato', marker='s', linestyle='--', label='Shop B')
plt.legend()
plt.show()

LEVEL 5

Bar charts for categories

Use bars to compare amounts for different named categories, not to imply continuous movement.

Python · runnable example
import matplotlib.pyplot as plt

fruits = ['Apple', 'Mango', 'Orange']
sales = [20, 35, 14]
plt.bar(fruits, sales)
plt.title('Fruit Sales')
plt.ylabel('Units')
plt.show()

LEVEL 6

Horizontal bars and sorting

Horizontal bars are useful when category labels are long. Sort data before graphing to make rankings easy to read.

Python · runnable example
import matplotlib.pyplot as plt

items = ['Rice', 'Oil', 'Flour']
amounts = [40, 25, 35]
pairs = sorted(zip(amounts, items))
plt.barh([name for value, name in pairs], [value for value, name in pairs])
plt.xlabel('Quantity')
plt.show()
Try it yourself: Sort the same data in descending order instead.

LEVEL 7

Scatter plots and relationships

A scatter plot shows two measurements for each observation. A rising pattern suggests an association, not necessarily causation.

Python · runnable example
import matplotlib.pyplot as plt

hours = [1, 2, 2.5, 3, 4, 5]
marks = [30, 40, 43, 54, 67, 75]
plt.scatter(hours, marks)
plt.xlabel('Study hours')
plt.ylabel('Marks')
plt.show()

LEVEL 8

Histograms and distributions

Histograms group numerical measurements into intervals called bins. Unlike bar charts, adjacent bins represent a numerical range.

Python · runnable example
import matplotlib.pyplot as plt

marks = [25, 35, 38, 41, 48, 51, 55, 58, 63, 67, 72, 76, 81, 88]
plt.hist(marks, bins=[20, 40, 60, 80, 100], edgecolor='black')
plt.xlabel('Marks')
plt.ylabel('Student count')
plt.show()
Try it yourself: Use 2 bins and then 8 bins. Describe how the story changes.

LEVEL 9

Pie charts: parts of a whole

A pie chart is useful only when positive parts add up to one meaningful whole. Avoid it for too many categories.

Python · runnable example
import matplotlib.pyplot as plt

labels = ['Food', 'Travel', 'Books']
spending = [50, 30, 20]
plt.pie(spending, labels=labels, autopct='%1.0f%%')
plt.axis('equal')
plt.show()

LEVEL 10

Subplots and object-oriented plotting

Figure and Axes objects offer precise control. fig, ax = plt.subplots() is the foundation for reusable charts and dashboards.

Python · runnable example
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(9, 4))
axes[0].plot([1, 2, 3], [2, 4, 3])
axes[0].set_title('Trend')
axes[1].bar(['A', 'B', 'C'], [3, 5, 2])
axes[1].set_title('Comparison')
fig.tight_layout()
plt.show()

LEVEL 11

Ticks, limits, annotations and grid

Good scales prevent misleading comparisons. Annotations call attention to meaningful events.

Python · runnable example
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.plot([1, 2, 3, 4], [10, 18, 14, 26], marker='o')
ax.set(xticks=[1, 2, 3, 4], ylim=(0, 30), title='Weekly progress')
ax.annotate('Best', xy=(4, 26), xytext=(2.7, 28), arrowprops={'arrowstyle':'->'})
ax.grid(alpha=0.3)
plt.show()

LEVEL 12

Error bars and uncertainty

Data often come from measurements or samples. Error bars communicate a range, but the meaning of that range must be stated.

Python · runnable example
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
mean = [5, 7, 6, 9]
uncertainty = [0.5, 0.8, 0.6, 1.1]
plt.errorbar(x, mean, yerr=uncertainty, fmt='o-', capsize=4)
plt.title('Mean with measurement uncertainty')
plt.show()
Try it yourself: Find the lower and upper bound for the fourth measurement.

LEVEL 13

Box plots and outliers

Box plots summarize the median, quartiles, spread and potential outliers of one or more numerical samples.

Python · runnable example

LEVEL 14

Functions, reusable styles and saving

Wrap plotting in functions, use consistent styling and save images with tight bounding boxes. In a browser editor, local file saving may differ from desktop Python.

Python · runnable example
import matplotlib.pyplot as plt

def draw_sales(names, values):
    fig, ax = plt.subplots(figsize=(7, 4))
    ax.bar(names, values, color='steelblue')
    ax.set(title='Shop Sales', ylabel='Units sold')
    fig.tight_layout()
    return fig

fig = draw_sales(['Mon', 'Tue', 'Wed'], [12, 19, 15])
fig.savefig('shop-sales.png', dpi=150, bbox_inches='tight')
plt.show()
Try it yourself: Change the function to accept a custom chart title.

LEVEL 15

NumPy, curves and mathematics

NumPy creates arrays of numbers. Matplotlib turns mathematical functions into visible curves; sampling density affects smoothness.

Python · runnable example
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 200)
y = np.sin(x)
plt.plot(x, y)
plt.axhline(0, color='gray', linewidth=0.8)
plt.title('Sine wave')
plt.show()

LEVEL 16

Pandas, dates and real-world CSV data

Pandas groups and cleans tables. Matplotlib presents the result. Start with an in-memory table so the first run does not depend on file upload.

Python · runnable example
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({'Date':['2026-11-01','2026-11-02','2026-11-03'], 'Sales':[120, 180, 160]})
df['Date'] = pd.to_datetime(df['Date'])
fig, ax = plt.subplots()
ax.plot(df['Date'], df['Sales'], marker='o')
ax.set(title='Daily sales', ylabel='Sales')
fig.autofmt_xdate()
plt.show()
Try it yourself: Read a CSV with Date and Sales columns on a desktop Python installation.

LEVEL 17

Heatmaps and two-dimensional data

Heatmaps map numerical values to colours. Always include a colour bar and label the values or units.

Python · runnable example
import numpy as np
import matplotlib.pyplot as plt

values = np.array([[1, 3, 2], [4, 5, 1], [2, 4, 6]])
fig, ax = plt.subplots()
image = ax.imshow(values, cmap='Blues')
fig.colorbar(image, ax=ax, label='Score')
ax.set(title='Scores by group')
plt.show()
