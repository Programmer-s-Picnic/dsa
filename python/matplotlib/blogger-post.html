📍 Lesson 0: Draw your very first point

We begin by learning that the point (2, 3) means travel two units right and three units up. That's all you need to understand your first chart.

import matplotlib.pyplot as plt

plt.plot(2, 3, marker='o')
plt.xlim(0, 5)
plt.ylim(0, 5)
plt.grid(True)
plt.show()

Try it: Change plt.plot(2, 3, marker='o') to plt.plot(4, 1, marker='o'). Predict where the dot moves before you run the program.

📈 From one dot to a complete line chart

import matplotlib.pyplot as plt

days = [1, 2, 3, 4]
visitors = [12, 18, 16, 25]

plt.plot(days, visitors, marker='o')
plt.title('Visitors by Day')
plt.xlabel('Day')
plt.ylabel('Visitors')
plt.grid(True)
plt.show()

You can change the numbers and watch the chart respond. Champuter can explain the imports, variables and plotting statements.
