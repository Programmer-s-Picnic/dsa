What is a DataFrame?

A DataFrame is a two-dimensional table: rows represent records and columns represent fields. Think of a class register with a student's name, city and marks. Each column has a label, and every row has an index.

You do not need CSV, Excel or a database to start. Create a DataFrame from Python values first.

RowNameCityMarksFeePaid
0AshaVaranasi88True
1RaviRanchi42False
2MeeraVaranasi76True
3KabirPatna91False
Python · pandas
import pandas as pd

students = pd.DataFrame({
    "Name": ["Asha", "Ravi", "Meera", "Kabir"],
    "City": ["Varanasi", "Ranchi", "Varanasi", "Patna"],
    "Marks": [88, 42, 76, 91],
    "FeePaid": [True, False, True, False]
})

print(students)

Before you begin: Install Pandas with python -m pip install pandas, then run the example in a Python environment. Check the installed version with print(pd.__version__).
