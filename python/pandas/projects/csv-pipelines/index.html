How a multi-stage pipeline works

Stage 1→stage01.csv→Stage 2→stage02.csv→Stage 3 → 4 → 5→stage05.csv→Stage 6→report.csv

Each stageNN.py reads input/… or the immediately preceding output/stageNN.csv. The master run_pipeline.py runs stages 1–6 in order and stops on an error. Stage-specific inputs, such as marks or an answer key, can be joined in addition to the preceding output.

Begin with CSV I/O and merging DataFrames if these operations are new to you.

Run a complete pipeline locally

Each project includes actual Python sources, reproducible sample input files, starter exercises and test code. No registration or external API is required.

Terminal · example using Student Results
python -m pip install pandas
cd python/pandas/projects/csv-pipelines/student-results
python run_pipeline.py
python -m unittest discover -s . -p "test_*.py"

# Or run one stage at a time:
python stage01.py
python stage02.py
python stage03.py
python stage04.py
python stage05.py
python stage06.py

Important: these projects demonstrate deterministic CSV-to-CSV batch processing. Data must be checked for duplicate keys, invalid values, unmatched joins and business-rule conflicts. Do not use sensitive real-world records in a public teaching repository.
