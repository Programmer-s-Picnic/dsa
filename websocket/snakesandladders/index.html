Multiplayer Snakes and Ladders

Protected player positions, persistent player identity, computer takeover when somebody leaves, and automatic return to the same role.

Interface View Student View includes setup. Player View keeps the board compact.

How It Works

1
Permanent player identity

A unique ID is stored in local storage on this browser.

2
Protected role

A connected player position cannot be taken by another user.

3
Computer takeover

If a player leaves during a game, the computer continues from the same position.

4
Automatic comeback

The same permanent ID can return and take control from the computer.
