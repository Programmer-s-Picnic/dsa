Before you begin

No previous ASP.NET experience is required. Basic C# familiarity helps, but the first lessons explain terminology carefully. Allow 20–40 minutes per lesson and do the checkpoints before moving on.

What will you build? First a small greeting website, then a URL-based application and a JSON API. Later modules will introduce forms, databases, authentication, deployment and advanced architecture.
